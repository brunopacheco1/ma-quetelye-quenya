# Specs

Feature specifications created with [Spec Kit](https://github.com/github/spec-kit).
Each feature gets its own numbered folder (for example `001-chapter-2/`) holding
`spec.md`, `plan.md` and `tasks.md`.

Flow: `/speckit-specify` → `/speckit-plan` → `/speckit-tasks` → `/speckit-implement` → `/speckit-converge`.
Every feature must comply with the [constitution](../.specify/memory/constitution.md).
